# План восстановления «Мастерской Веры»

## Цель
Восстановить сайт по найденным визуальным материалам, сохранив атмосферу старого проекта и одновременно сделать адаптивный, аккуратный и технически чистый интерфейс.

## Источник истины
1. Найденные скриншоты и концепты из архива.
2. Фото и декоративные элементы из того же архива.
3. Фактическая реализация после визуальной сверки.

## Этапы

### 1. Инвентаризация референсов — текущий этап
- 83 изображения разобраны на `screen`, `decor`, `photo`.
- Зафиксирован manifest с исходными именами и размерами.
- Определены ключевые экраны: главная в светлой/тёмной композиции, «Зимние легенды», каталог/коллекция, карточка персонажа/товара.

Критерий готовности: для каждого изображения известна роль; ключевые экраны выделены.

### 2. Фундамент сайта
- базовая структура проекта;
- дизайн-токены: фон, бумага, дерево, золото, бордовый/зелёный акцент;
- типографика, контейнеры, кнопки, карточки;
- header/footer, desktop + mobile.

Критерий готовности: общий каркас визуально совпадает с референсами и не ломается на 360/390/430 px.

### 3. Главная страница
Восстановить композицию из референсов #13/#14/#20/#30/#49: hero, мир/жители, готовые работы, история мастерской, CTA.

### 4. Тематическая коллекция «Зимние легенды»
Ориентиры #29/#50/#66. Сохранить отдельное зимнее настроение и общий язык бренда.

### 5. Каталог / «Жители»
Ориентиры #37/#58. Карточки, категории, фильтры, состояния, мобильная сетка.

### 6. Карточка изделия / персонажа
Ориентиры #65/#68/#72/#82. Галерея, история, характеристики, цена/заказ, связанные работы.

### 7. Второстепенные страницы
Мастерская, индивидуальный заказ, доставка/оплата, контакты и другие разделы, подтверждённые референсами.

### 8. Mobile-first доводка
Отдельно проверить меню, типографику, touch targets, изображения, длинный контент и отсутствие горизонтального скролла.

### 9. Финальная визуальная сверка
Экран к экрану: пропорции, отступы, шрифты, декор, кадрирование фото, состояния кнопок.

### 10. Техническая полировка
Оптимизация изображений, performance, accessibility, SEO, PWA/deploy только после визуального восстановления.

## Что не делаем сейчас
Не придумываем новый стиль вместо найденного, не добавляем лишние библиотеки, не настраиваем deploy и не меняем дизайн без необходимости.

## Следующий шаг
Создать каркас сайта и дизайн-токены, затем собрать header + первый экран главной по референсам #13/#14.
