## Осталось (по порядку)

Восстановление дизайна продолжается. Функциональная база и данные собраны, но визуально сайт ещё не считать финальным.

1. Главная — восстановление по старым одобренным скринам продолжается. Финальным направлением считается светлая кремовая версия: gallery-hero «Создано руками. Выбрано сердцем.», светлый блок О мастерской, тёмный блок 5 Миров, светлая витрина Жителей и тёмный CTA.
2. Миры — подтверждённые desktop/mobile подложки уже подключены на главной и на страницах конкретных Миров; восстановлена композиция hero + список Жителей. Картуши/дополнительный декор подключать только после подтверждения назначения.
3. Жители — все 17 карточек сверены: в каталоге используются подтверждённые «мирные» фото (Кот в сапогах остаётся подтверждённым исключением до отдельного решения); восстановлены прямые переходы «Войти в Мир» из каждой полосы, мобильные действия карточек ≥44 px. Дальше — только точечный визуальный проход по новым скриншотам.
4. Хроники — hero и тёмный блок истории/характеристик восстановлены. Галерея «Рассмотреть ближе» заблокирована до подтверждённого сопоставления студийных фото: в git сейчас есть только мирные фото, дублировать их вместо честных ракурсов нельзя.
5. О мастерской / Как создаются / Контакты — второй визуальный проход завершён по коду: конфликтующие сетки, хардкод статистики, широкоформатное сжатие и иконка контактов исправлены; типографика вторичных заголовков унифицирована. Дальше — финальный QA.
6. Только после этого — настоящий финальный mobile QA 320/360/390/430 и релизная проверка.
7. Реальные отзывы — добавить только после получения источника; не выдумывать.
