## 1. Дизайн-токены (уже утверждено, не менять без причины)

```css
--paper: #f0e3cd        /* кремовая бумага, светлые секции */
--paper-light: #fbf4e7  /* светлее, чередующиеся полосы */
--night: #120d0b        /* почти чёрный тёплый, тёмные секции */
--wine: #78272b         /* акцент (сейчас используется по минимуму) */
--gold: #b78a4f          /* золото — рамки, линии, акцент */
--gold-ink: #7a5d34      /* золото на светлом фоне (контраст) */
--gold-light: #e8c98f    /* золото на тёмном фоне */
--ink: #261a15           /* тёмный текст на бумаге */
--muted: #76665a         /* приглушённый текст */
--display: Cormorant Garamond   /* все заголовки, вес 500 */
--body: Manrope                 /* весь остальной текст */
--shell: 82rem            /* общая ширина контента, ОДНА переменная, не хардкодить */
```

Ритм секций (утверждённый, воспроизводить): **бумага → ночь → бумага → ночь
→ бумага → ночь → футер(ночь)**. Не делать всё тёмным (плоско, секции
сливаются) и не всё светлым (бренд построен на контрасте бумага/ночь).

Шрифты: заголовки Cormorant, tracking -0.045em, line-height ~0.96-1.1.
Overline-подписи над заголовками: Manrope 700, 11-12px, letter-spacing 0.2em,
золото.

## 4. Фото — система из ДВУХ ролей на Жителя (важно!)

У каждого Жителя **два типа фото**, каждое — своя роль, путать нельзя:

1. **«Мирное» фото** — Житель на пьедестале в своём Мире (зимняя деревня с
   огнями, дупло дерева, пещера с котлами, солнечная комната с занавеской,
   ночной лес с луной — у каждого мира свой фон). Идёт в: карточку каталога,
   слайд Мира, шапку Хроники. Это витрина, должна цеплять.
2. **Честное/студийное фото** — просто фигурка, без постановки, как она
   есть. Идёт в блок «Рассмотреть ближе» под описанием — чтобы покупатель
   не разочаровался, когда фигурка приедет обычной, а не в лесу.

**Был найденный и починенный баг**: шаблон карточки просил мирное фото, а
скрипт дорисовки затирал его сырым — в каталоге все Жители висели «в руке
над асфальтом» вместо своего мира. Проверять на будущее: карточка каталога
должна показывать именно мирное фото.

Обе версии фото у Дмитрия УЖЕ ЕСТЬ на диске (архив 83 фото в
`references/raw-archive/`) — они не потеряны, только сама сборка сайта.

### Частицы миров — canvas-движок, не CSS
Финальная версия: **canvas**, не DOM-узлы. Снег/светлячки/угли/пыль — у
каждого типа своя физика. Оптимизировано (см. п.7) до 36кадров/сек, максимум
2 слоя одновременно, останавливается при скрытой вкладке. Переход цвета
воздуха страницы между мирами — через `IntersectionObserver` по
`data-world`, при скролле по «Жителям» атмосфера меняется на лету.

## 7. Технические грабли (уже найдены и решены — не наступать повторно)

1. Порядок подключения CSS-файлов важен: `site-fixes.css` должен идти
   **последним** во ВСЕХ файлах (была рассинхронизация — на главной он
   стоял раньше `home-redesign.css`, отсюда «правки будто не применяются»)
2. `position: sticky` не работает, если обёртка элемента ровно его высоты —
   элементу «некуда липнуть». Высоту шапки — только через одну CSS-переменную,
   не хардкодить в 5 местах
3. `overflow: hidden` на секции (ради скруглённых углов) режет всё, что
   вылезает за её верхний край — включая псевдоэлементы-декор
4. `scrollIntoView()` в автопрокрутке двигает ВЕСЬ документ, а не только
   контейнер — нужен `track.scrollTo()` на самом элементе
5. Лайтбокс/галерея: адрес полноразмерного фото нужно брать с самого
   элемента клика, не дублировать в отдельном атрибуте — на сборке с
   base-path (GitHub Pages) второй адрес не проходит через тот же фикс путей
6. Ленивые картинки без `aspect-ratio`/резерва места — схлопывают ячейку до
   загрузки, отсюда прыжки страницы и случайные тапы по «невидимым» кнопкам
7. Меню на мобильном: если блокировать скролл через `overflow:hidden` на
   `body`, а прокручивается `html` (или наоборот) — открытое меню улетает
   вместе с шапкой при sticky-позиционировании. Лочить скролл лучше через
   `touch-action: none` на затемнении, а не через overflow-хаки
   Закрывать меню всеми способами сразу: крестик, пункт, тап мимо, Esc
8. Контраст: некоторые CSS-переменные под контраст (`--gold-ink`) заводили
   в токенах, но забывали использовать в конкретных местах — проверять
   реальным замером (4.5:1), не на глаз
9. Старостильные цифры у Cormorant Garamond визуально мельче обычных — если
   «цифры маленькие», сначала проверить не размер, а начертание шрифта
10. Google Fonts первой строкой в CSS = блокирующая загрузка (в РФ доступ к
    Google нестабилен) — шрифты подключать асинхронно, с системным
    fallback (Georgia/Arial), первая отрисовка была 13.2с → 0.22с после фикса
11. `brightness()`/`saturate()` фильтры в CSS гасят фото на 30%+ — генерируя
    исходники под такие места, делать их заметно ярче/насыщеннее, чем
    хочется на глаз в файле
